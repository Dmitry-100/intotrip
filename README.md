# Intotrip China MVP

Astro static MVP for `intotrip.ru/china`.

## Short mobile commands for Дмитрий

- `mvp` — build/continue local MVP site.
- `dns` — domain/DNS check or next DNS step.
- `tp` — Travelpayouts / affiliate links / tracking.
- `seo` — generate or improve SEO content backlog.
- `tg` — Telegram channel posts/content.
- `paid` — paid traffic test plan/creatives.
- `ship` — prepare deploy checklist.
- `audit` — run build/checks and report what works.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
